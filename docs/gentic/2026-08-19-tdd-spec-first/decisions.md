# Decisions: tdd-spec-first

Interview conducted non-interactively under the standing delegation recorded on 2026-08-11
("decide everything I fully trust you to"), which directs judgment calls to be made and flagged
rather than asked. None of the decisions below fall into the categories gentic reserves for the
user regardless of delegation — no security, money, other people's data, or irreversible action.
Every row is therefore `default — unconfirmed` and is surfaced again in the final report.

| Decision | Chosen | Alternatives considered | Why | Source |
|----------|--------|------------------------|-----|--------|
| Where the TDD discipline lives | New `gentic-tdd` skill, invoked per task by `gentic-execute` | Expand the inline rule inside gentic-execute; keep delegating to superpowers | A dedicated skill is how superpowers factors the discipline and the only option that makes it self-contained without pushing gentic-execute past its readable length. Delegation-only fails the repo's own rule that no markdown may reference a superpowers skill unconditionally (test_structure.py:171). | default — unconfirmed |
| How much test design the spec carries | Every DoD item gains a **test contract**: test file, test name, behaviour asserted, expected RED message. Literal test code stays at Execute time. | Full superpowers `writing-plans` style literal test code in the spec; DoD keeps only its verify command | Gentic separates spec (`masterprompt.md`) from plan (`progress.md` task table); superpowers' literal-code plans are the analogue of the task table, not of the spec. The contract is what makes the spec *drive* test design; the code is what Execute writes test-first. Putting code in the spec would duplicate it and bloat the stranger-test artifact. | default — unconfirmed |
| Durable RED evidence | Task table gains `Test` and `RED` columns; a task may not be marked done with an empty `RED` cell | Leave the table as-is and trust the transcript | The workflow's stated principle is that the run directory carries state, not memory. RED evidence is today the only evidence with nowhere to live, which is why the fan-out path demands it (task-executor) and the solo path does not. Columns make the discipline structural rather than exhortative. | default — unconfirmed |
| Hook enforcement strength | Ledger starts recording **failing** verification runs as RED evidence; `stop.py` gains an **advisory** TDD nudge, at most once per session | A second hard block; no hook change at all | `stop.py:4-7` documents the single-gate rule — "a second adversarial gate would make the setup something to work around rather than with". Teeth come instead from the skill's Iron Law, the spec's test contracts, and the un-fillable RED column; the hook contributes signal, not a second veto. | default — unconfirmed |
| Scope outside gentic runs | Machine-wide: the hook nudge applies to any code change in any session; the skill discipline stays gentic-owned and is invoked by gentic-execute | Restrict the nudge to active gentic runs | Hooks already run machine-wide and would need new coupling to detect an active run. An advisory nudge is cheap enough to be always-on; a block would not have been. | default — unconfirmed |
| Tasks with no executable behaviour | The contract test is the test: a task that changes documented behaviour must add or extend a contract test. Only a task changing nothing observable may declare `n/a` in the `Test` column, with a stated reason. | Exempt docs/prose tasks from TDD entirely | This repo already tests its own markdown (`test_structure.py`), so the precedent exists and the escape hatch is narrow. A blanket exemption would let any prose-shaped task — a large share of this repo's work, including this run — opt out of the discipline being introduced. | default — unconfirmed |
| Framing of the change | Deepen the existing five phases; do **not** add a sixth phase | Add a "Test design" phase between Masterprompt and Execute | The phase count is load-bearing in docs, tests and user habit. Test design belongs inside the spec that already exists rather than in a new gate. | default — unconfirmed |
